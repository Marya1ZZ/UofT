# HAD7001 Applied Machine Learning in Healthcare
## Posting Datathons
#Datathon 4: mHealth Wearables - Activity Classification with LSTM

## Overview

This repository contains the project developed for Datathon 4, focusing on leveraging machine learning and wearable sensor data for classifying physical activity levels. Our solution utilizes an LSTM neural network to predict physical activity intensity, aiming to support targeted health interventions and proactive health management.

## Repository Structure

/Report/06-HAD7001-S25.pdf: Full project report detailing objectives, methodology, results, and discussions.

/Code/Datathon_4.ipynb: Jupyter notebook with Python code including data preprocessing, feature engineering, model training, and evaluation.

/Presentation/Datathon 4 Wearables LSTM.pdf: Presentation slides summarizing key findings, challenges, and future directions.

## Dataset

The dataset used was provided by Sunnybrook Health Sciences Center and contains time-series sensor data collected from wearable devices.

13 activity classes were classified, ranging from sedentary behaviors to vigorous activities.

## Key Findings

Achieved overall accuracy of 91% using an LSTM neural network.

Noted strong performance in classifying sedentary and vigorous activities.

Challenges include model explainability, class imbalance, and limited generalizability due to dataset demographics.

## Future Work

Enhance interpretability through SHAP feature importance analysis.

Explore advanced neural network architectures (e.g., bidirectional LSTM, attention mechanisms).

Validate the model with more diverse and extensive datasets.
